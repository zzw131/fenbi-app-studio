# AI / Gemini 开发任务简报

> 如果你是刚导入本仓库的 AI（Gemini / Claude / 任意编码助手），**先读这份文件**，它用最短路径告诉你这里有什么、怎么定位素材、能做什么。

## 1. 这是什么

这是「粉笔教育」Android App 的界面与交互素材库，不是现成的应用代码。它记录了 App 的**真实界面长什么样**（截图）和**点击哪里跳到哪里**（结构化数据 + 思维导图）。你的任务通常是：基于这些素材**复刻 / 重建**一个可运行的界面原型，或生成交互文档、测试脚本。

## 2. 快速理解结构（按顺序读）

1. **`app-structure.json`** — 最重要。里面有：
   - `meta`：App 基本信息
   - `navigation_flow`：启动→登录→向导的顺序流程，每步含 `trigger`（触发动作）和 `target`（跳转目标）
   - `main_tabs`：主界面 5 个 Tab，每个含 `elements`（页面元素）和 `actions`（可点击项→跳转）
   - `quiz_flow`：答题流程
   - `global_functions`：全局功能
   - `screenshot_index`：17 张截图的「文件→页面」映射
2. **`界面截图索引与跳转说明.md`** — 人类可读版，可交叉核对
3. **`../screenshots/`** — 布局与视觉参考。文件名前的序号对应流程顺序
4. **`../mindmap/粉笔教育App界面与跳转结构.xmind`** — 树状结构总览

## 3. 截图命名规律

文件名格式 `序号_页面名.png`，序号即用户操作顺序：
- `01`~`07`：启动、登录、目标定制向导
- `08`~`12`：主界面 5 个 Tab（练习/课程/选岗/发现/我）
- `13`~`14`：答题页、答题卡弹窗
- `15`~`17`：选岗助手二级页面

## 4. 你可以做什么（建议任务）

- **复刻 UI 原型**：用 React / HTML+CSS 按截图还原 17 个页面，并按 `navigation_flow`、`actions` 实现点击跳转，组成一个可点击的高保真原型
- **生成交互文档**：把 JSON 转成表格化 PRD / 用户流程图
- **编写自动化测试**：根据 `trigger → target` 生成 UI 遍历脚本
- **设计稿标注**：基于截图输出每个页面的元素清单与布局说明

## 5. 约束与注意事项

- 截图中标注「未采集」的页面（登录子页、课程/职位详情、搜索页）没有截图，请勿凭空杜撰其精确视觉，可用占位并说明
- 主界面为单 Activity + 多 Fragment 结构，底部固定 5 个 Tab
- 滑块验证码为第三方安全验证，复刻原型时可用模拟开关代替
- App 品牌色为蓝色（粉笔蓝，约 `#3A7AFE` / `#4A90E2` 系）
- `assets/fenbi.apk` 通过 Git LFS 存储，导入工具可能只拿到指针文本；复刻界面不需要 APK，直接看截图即可

## 6. 建议的第一步

阅读 `app-structure.json` 后，向用户复述一遍「启动→主界面→练习答题」的主线跳转，确认理解无误，再开始编码。
