# 粉笔教育 App（Android）界面截图索引与跳转说明

> 采集方式：Android 模拟器（capture_phone / Android 15），官方 APK v6.19.6
> 包名：`com.fenbi.android.servant`
> 采集时间：2026-11-19

---

## 一、启动与登录流程

| 序号 | 截图文件 | 页面 | 点击跳转 |
|---|---|---|---|
| 01 | 01_用户协议弹窗.png | 用户协议和隐私政策 | 点「同意并继续」→ 登录选择页；点「不同意」→ 退出 |
| 02 | 02_登录选择页.png | 登录选择 | 点「随便逛逛」→ 安全验证（滑块）；「短信验证码登录」/「账号密码登录」→ 对应登录页 |

> 说明：「随便逛逛」会触发第三方**滑块拼图安全验证**，验证通过后才可进入 App。

## 六、整体跳转逻辑速览

```
启动
 └─ 用户协议 ─ 登录选择 ─ (随便逛逛 → 滑块验证)
       └─ 目标考试选择 ─ 考试类型 ─ 笔试/面试 ─ 地区 ─ 类别 ─ 新人福利
             └─ 主界面 ─┬─ 练习 ─ 科目 ─ 答题页 ─ 答题卡 ─ 交卷
                        ├─ 课程 ─ 分类 ─ 课程详情
                        ├─ 选岗 ─ 考试类型 ─ 完善信息 / 职位列表
                        ├─ 发现 ─ 推荐/圈子/干货/经验/关注
                        └─ 我 ─ 登录/会员/订单/消息/客服...
```
